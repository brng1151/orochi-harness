Usage: oh [--profile] <name> [options] [app-args...]
       oh plugin --profile <name> <pnpm-args...>

oh: boot a Orochi Harness profile — an ordered stack of plugin-bundle patch
layers under your own overrides.

Arguments:
  args                           arguments for the booted profile's app (see:
                                 oh --profile <name> --help)

Options:
  -V, --version                  output the version number
  --profile <name>               the profile under $OH_HOME/profiles to boot
  --from-default-profile <name>  initialize a new custom profile from a shipped
                                 profile template
  --patch <path>                 extra patch-list overlay applied after the
                                 profile layer (repeatable)
  --dump-config                  print the composed profile tree and exit
  --dump-config-schema           print JSON Schema for profile entries and
                                 patches without mounting
  --dump-default-config          print the profile tree without its user layer
                                 or --patch overlays and exit

Examples:
  oh web                                   boot the web profile (same as: oh --profile web)
  oh rescue --from-default-profile web
                                            create rescue from the shipped web template, then boot it
  oh headless "run the tests"              answer one task, print the result, and exit
  oh tui --patch ./extra.yml               boot a custom profile with one extra overlay
  oh tui --resume <session>                arguments after the launcher flags reach the app
  oh web --help                            the web app's own flags and help
  oh plugin --profile tui add <package>    install a plugin into the tui profile
